Getting the numbers in

LinkedIn does not let tools read a page's views and clicks without special approved access, so there are three ways to bring the numbers in:

  1. Screenshot. Open the post's analytics in LinkedIn, take a screenshot, and let the AI read the numbers off it.
  2. Type them in from LinkedIn's post analytics.
  3. Tracked link. Each post has a link with campaign tags. When people click it, your Google Analytics shows website visits from that exact post (Reports, Acquisition, Traffic acquisition, then look for the campaign content-studio).

Guide

How Galleypost works

Six short notes. Open this from the sidebar, Cmd+K, or the ? in the header.

  1. What Galleypost does

    Galleypost is a content desk: it turns a brand profile and sourced facts into a LinkedIn or Instagram draft you can review. It does not invent numbers, and it does not publish anything on its own. Named after the galley proof: the newsroom proof that gets checked before anything goes to print.

  2. Quick start

    1. Brand. Paste a website URL and extract a profile, or load the London Tech Community demo.
    2. Studio. Find topics or add your own facts, then write a post.
    3. Review. Read the fact-check notes, checklist and preview. Edit anything that is not sourced.
    4. LinkedIn. Press Post on LinkedIn. That opens LinkedIn’s composer in a new tab with the draft filled in, and copies the text to the clipboard as a fallback. It does not auto-publish — you press Post in LinkedIn yourself.

  3. Posting to Instagram

    Open in Instagram (no token): copies the caption, downloads the image if there is one, and opens instagram.com in a new tab so you can press + Create in your logged-in session. Publish via API needs INSTAGRAM_ACCESS_TOKEN, INSTAGRAM_USER_ID, and PUBLIC_BASE_URL. Without those it is a labelled dry-run. Captions are capped at 2,200 characters and 30 hashtags. API publish still waits for you to confirm.

  4. Settings

    Local: copy .env.example to .env and set OPENAI_API_KEY, then restart. Hosted on Vercel: set OPENAI_API_KEY and APP_PASSWORD in project env vars (the browser asks for that password). Appearance: light is the default; switch to dark under Settings. The choice stays in this browser.

  5. Troubleshooting

    ProblemWhat happens / what to do
    No OpenAI keyDemo mode: Studio and Classic still open. Live research, writing and images stay locked until OPENAI_API_KEY is set and the server is restarted.
    Instagram dry-runToken or user id missing. Use Open in Instagram for your logged-in session, or press Publish via API for a labelled dry-run. Nothing is published until you confirm.
    Port in useAnother process has 8080. Stop it, or run with another PORT. The Mac launcher will not kill the other app.
